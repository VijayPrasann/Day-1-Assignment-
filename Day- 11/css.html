Task 3: The Centered Block (The Old Way)

The box below has a width of 50% and is centered horizontally using margin: 0 auto;.

Centered Box

This is a 50% wide block element. It is centered horizontally using margin: 0 auto;.

Why doesn't this center vertically?

margin: 0 auto; automatically distributes the left and right margins, so it centers the element horizontally. It does not automatically distribute the top and bottom space, so it does not vertically center the element.
