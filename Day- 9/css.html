Task 6: Box Model Formula

The total width of an element using the default content-box model is:

Total Width = Content Width + Left Padding + Right Padding + Left Border + Right Border

Example:

300px width + 20px left padding + 20px right padding + 10px left border + 10px right border

Total Width = 360px

📌 Box Model Summary

Every HTML element is treated as a rectangular box.

Content → Padding → Border → Margin

Content: The actual text or element inside the box.

Padding: Space between the content and border.

Border: The line surrounding the padding and content.

Margin: Space outside the border.
